# PulseCart

PulseCart is a modern e-commerce web application designed to provide a smooth and user-friendly online shopping experience.

## Project Overview

PulseCart allows users to:

- Browse products
- Search and filter products
- View product details
- Add products to the cart
- Manage cart items
- Place orders
- Manage user accounts
- Track order information

## MVP

The Minimum Viable Product (MVP) focuses on the core shopping experience:

1. User registration and login
2. Product listing
3. Product search
4. Product details
5. Shopping cart
6. Checkout/order placement
7. Basic user profile
8. Backend REST APIs
9. PostgreSQL database integration
